# QUIZVERSE first prototype

## Run it
Open `index.html` in a browser, or upload the folder contents to a static web host.

## Included
- Responsive quiz interface for mobile and desktop
- Six quiz categories and a daily mixed challenge
- 5 multiple-choice questions per category
- Score, best score, total points and local leaderboard
- Premium preview and ad placement placeholder
- Web app manifest and service worker for installable/offline-friendly use

## Important
This is a prototype. Scores are stored only in the browser/device using localStorage. There is no shared online leaderboard, login, cloud database, live advertising, subscription billing or payment processing yet. The ad area is only a placeholder.

## Free publishing route
A static host such as GitHub Pages can serve the web app for free. After publishing over HTTPS, open the URL in Chrome on Android and use the browser menu > Add to Home screen / Install app (wording varies).
